# 📋 KBLI & Business Licensing Validator (PP 28 / OSS-RBA)

> **Web Application & Compliance Validator** for verifying Indonesian Standard Industrial Classification (KBLI) and risk-based business licensing according to Government Regulation No. 28.

## 🎯 Purpose & Features

- 🔍 **Instant KBLI Validation**: Quickly verify 5-digit KBLI codes and corresponding business sector definitions.
- ⚖️ **PP 28 Compliance Checking**: Filter licensing parameters and evaluate business risk levels (Low, Medium-Low, Medium-High, High).
- 🎨 **Clean & Responsive UI**: Streamlined interface optimized for desktop and mobile devices.
- ⚡ **Zero Bloat**: Lightweight implementation using semantic HTML and Tailwind CSS.
